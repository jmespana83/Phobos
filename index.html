Core database capabilities

Built around correctness first.

PHOBOS is designed as a real transactional database engine—not a wrapper around SQLite and not a mock SQL layer. Its core is centered on durable writes, transactional isolation, recovery, and database administration.

TX

MVCC & Transactions

Transactional reads and writes with rollback, concurrency control, explicit transaction handling, and durable commit semantics.

WAL

WAL Durability

Write-ahead logging, restart recovery, WAL rotation handling, crash recovery, and integrity-oriented commit behavior.

SQL

Modern SQL Foundation

Joins, aliases, CTEs, subqueries, identity columns, RETURNING, persistent views, UNION, INSERT SELECT, constraints, and more.

FK

Relational Integrity

Primary keys, unique indexes, CHECK constraints, defaults, identity allocation, and foreign-key RESTRICT / NO ACTION semantics.

DR

Backup, PITR & Replication

Backup and restore, point-in-time recovery, standby/replication support, and offline integrity validation.

TLS

Security & TLS

Authenticated access, coarse admin/writer/reader authorization, TLS support, protected configuration, and secure installer defaults.

Quick Start

From download to your first query in minutes.

For the simplest Windows setup, install PHOBOS Community Edition 1.0.1, open PHOBOS Management Studio, connect to your local server using the credentials created during setup, and run your first SQL.

1

Install PHOBOS

Download the Windows x64 Setup package and complete the installer. Keep the server port and administrator credentials you choose during setup.

2

Open Management Studio

Launch PHOBOS Management Studio and create a connection to your local PHOBOS server using your configured port, administrator username, and password.

3

Run your first SQL

Create a table, insert a couple of rows, and use RETURNING to immediately see generated identity values.

-- Your first PHOBOS table
CREATE TABLE hello_phobos (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  message TEXT NOT NULL
);

INSERT INTO hello_phobos (message)
VALUES ('Hello, PHOBOS!'), ('My database is running.')
RETURNING id, message;

SELECT id, message
FROM hello_phobos;

✓ If you see your rows, PHOBOS is ready.
PHOBOS Community Edition 1.0.1 is qualified on Windows x64. If you changed the default server settings during installation, use the port and credentials you selected there.
Release status

Transparent about what is ready—and what is still evolving.

PHOBOS is a young database engine. The Windows x64 release is the primary qualified target today. The project documents unsupported SQL and platform limitations instead of pretending to be feature-equivalent to decades-old database systems.

Windows x64

Qualified target. Server, service lifecycle, installer, Studio, recovery, backup/restore and core SQL validation are exercised on Windows.

Linux

Cross-platform architecture, qualification pending. Linux release claims should only be made after native execution and package validation.

Performance

Performance remains under active qualification. Users should benchmark PHOBOS on their own hardware and workloads rather than relying on universal performance claims.

PHOBOS does not claim full SQL-standard compatibility or feature parity with PostgreSQL, SQL Server, Oracle, or MySQL. The goal is a capable, transparent, community-oriented relational database that continues to improve in public.
